# BridgeTech

> An e-learning platform bridging the gap between traditional university education and practical software industry requirements.

---

## Project Overview
BridgeTech is designed to help software engineering students learn modern development tools—such as Git, APIs, CI/CD, and Cloud basics—through structured modules, interactive quizzes, and hands-on exercises.

## Team Responsibilities
- **Main Branch:** Reserved for production-ready, fully tested releases. Do not push directly to `main`.
- **Feature Branches:** Create feature branches off `frontend` or `backend` (e.g., `feature/user-auth` or `feature/quiz-ui`).
- **Pull Requests:** All code changes must go through a Pull Request (PR) with at least one review.

## Branch Strategy
- `main` - Production / Stable releases
- `frontend` - Frontend application code and UI development
- `backend` - Backend APIs, database integration, and AI logic
